# DeskMon updates

macOS용 DeskMon의 **설치 파일과 자동 업데이트 정보만** 배포하는 저장소입니다. 소스 코드는 공개하지 않습니다.

[최신 설치 파일](https://github.com/jainefer/DeskMon-updates/releases/latest)

- Apple Silicon(M 시리즈) Mac, macOS 14 이상 대상.
- DMG에서 DeskMon.app을 Applications로 드래그한 뒤 실행하세요.
- Apple 공증을 받지 않은 개인 팬 프로젝트입니다. 최초 실행 시 macOS의 수동 허용이 필요할 수 있습니다.
- 1.2.0부터 자동 업데이트를 지원합니다. 그 이전 버전은 한 번 수동 설치해야 합니다.
- 설정에서 자동 업데이트를 끄거나 즉시 확인할 수 있습니다.
- 펫·코인 등 게임 저장 데이터는 각 Mac에 남으며 업데이트에도 유지됩니다.
- 펫 추가 요청은 앱의 '펫 추가 요청하기'를 사용하세요. 메일에 사진을 직접 첨부하고 전송합니다. 수동 검토 후 추가할 수 있으며, 반영 여부나 시기는 보장되지 않습니다.

업데이트 파일과 appcast는 Ed25519 서명으로 검증합니다. 서명 개인키 및 사용자 저장 데이터는 이 저장소에 포함되지 않습니다.

Pokémon 공식 제품이 아닙니다. 자동 업데이트에 사용하는 Sparkle은 별도의 오픈 소스 프로젝트입니다.
